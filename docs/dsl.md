# DSL для валидации презентаций

Данный DSL предназначен для описания правил оформления и валидации презентаций в учебных и профессиональных целях. С его помощью можно задать требования к структуре презентации, стилю слайдов, содержимому и другим аспектам.

## Общая структура

Конфигурация описывается внутри блока `presentationRules { ... }`, который включает два раздела:

- `structure { ... }` — правила на уровне всей презентации.
- `slide { ... }` — правила для каждого слайда.

```kotlin
val config = presentationRules {
    structure {
        // правила структуры
    }
    slide {
        // правила для слайдов
    }
}
```
## Structure Rules — структура презентации

Блок `structure { ... }` определяет правила на уровне всей презентации:

- допустимое количество слайдов;
- допустимые форматы слайдов;
- названия обязательных слайдов;
- ограничение на количество уникальных цветов.

### Пример использования

```kotlin
structure {
    slidesCountRange = 10 to 15
    requiredFormats("16:9", "4:3")
    mandatorySlides("Title", "Conclusion")
    limitColors = 3
}
```
### Описание параметров

| Свойство                | Тип              | Обязательное | Описание                                                                 |
|-------------------------|------------------|--------------|--------------------------------------------------------------------------|
| `slidesCountRange`      | `Pair<Int, Int>` | Да           | Устанавливает минимальное и максимальное количество слайдов.            |
| `requiredFormats(...)`  | `vararg String`  | Нет          | Указывает допустимые соотношения сторон слайдов (например, "16:9").     |
| `mandatorySlides(...)`  | `vararg String`  | Нет          | Определяет названия слайдов, которые обязательно должны присутствовать. |
| `limitColors`           | `Int`            | Нет          | Ограничивает максимальное количество уникальных цветов, используемых в презентации. |

---

### Подробности по каждому параметру

#### `slidesCountRange`

- **Тип:** `Pair<Int, Int>`
- **Описание:** Определяет допустимый диапазон количества слайдов.
- **Пример:**
```kotlin
slidesCountRange = 10 to 15
```
Презентация должна содержать от 10 до 15 слайдов.

`requiredFormats(...)`

- **Тип:** `vararg String` (например, "16:9", "4:3")
- **Описание:** Допустимые форматы слайдов по соотношению сторон.
- **Пример:**
```kotlin
requiredFormats("16:9", "4:3")
```
Презентация может быть в любом из указанных форматов.

`mandatorySlides(...)`
- **Тип:** `vararg String`
- **Описание:** Указывает названия обязательных слайдов. Названия проверяются на точное совпадение.
- **Пример:**
```kotlin
mandatorySlides("Title", "Conclusion")
```
В презентации должны быть слайды с такими названиями.

`limitColors`
- **Тип:** `Int`
- **Описание:** Ограничение на количество различных цветов, используемых в презентации (например, для фонов, текста, рамок и т.д.).
- **Пример:**
```kotlin
limitColors = 3
```
Не более трёх уникальных цветов.

## Style Rules — оформление и стилизация слайда

Блок `style { ... }` внутри `slide { ... }` задаёт правила, связанные со стилем и визуальным оформлением слайда. Состоит из вложенных блоков `fonts { ... }`, `colors { ... }`, а также параметра `limitFontVariety`.

### Пример использования

```kotlin
style {
    fonts {
        sansSerifRequired = true
        fontSizeRange(bodyMin = 18.0, bodyMax = 24.0)
        maxFontStyle(2, 1, 0)
    }
    limitFontVariety = 3
    colors {
        contrastThresholds(4.5, 3.0)
    }
}
```

### Описание параметров

| Свойство               | Тип                                           | Обязательное | Описание                                                                 |
|------------------------|-----------------------------------------------|--------------|--------------------------------------------------------------------------|
| `fonts { ... }`        | `FontsRules`                                  | Нет          | Блок с правилами для шрифтов.                                           |
| `sansSerifRequired`    | `Boolean`                                     | Нет          | Требует использование только шрифтов без засечек.                       |
| `fontSizeRange(...)`   | `bodyMin: Double`, `bodyMax: Double`, `titleMin`, `titleMax` | Нет          | Диапазоны размеров шрифта для основного текста и заголовков.            |
| `maxFontStyle(...)`    | `maxBold: Int`, `maxItalic: Int`, `maxUnderline: Int`          | Нет          | Максимальное количество применений стилей: жирный, курсив, подчёркнутый.|
| `limitFontVariety`     | `Int`                                         | Нет          | Максимальное количество разных шрифтов на слайде.                       |
| `colors { ... }`       | `ColorsRules`                                 | Нет          | Блок с требованиями к контрасту текста.                                 |
| `contrastThresholds(...)` | `minContrastForText: Double`, `minContrastForLargeText: Double` | Нет     | Минимальные значения контраста для обычного и крупного текста.          |

### Подробности по вложенным параметрам

#### `fonts { ... }`

##### `sansSerifRequired`

- **Тип:** `Boolean`

- **Описание:** Если установлено в `true`, все шрифты должны быть без засечек (sans-serif).

- **Пример:**
```kotlin
sansSerifRequired = true
```

`fontSizeRange(...)`
- **Тип:** Параметры типа `Double`
- **Описание:** Диапазоны допустимого размера шрифта.
- **Пример:**
```kotlin
fontSizeRange(bodyMin = 18.0, bodyMax = 24.0, titleMin = 28.0, titleMax = 36.0)
```

`maxFontStyle(...)`
- **Тип:** Три параметра типа `Int`
- **Описание:** Ограничивает количество стилей: жирный (bold), курсив (italic), подчёркнутый (underline).
- **Пример:**
```kotlin
maxFontStyle(2, 1, 0)
```

`limitFontVariety`
- **Тип:** `Int`
- **Описание:** Устанавливает ограничение на количество различных шрифтов, использованных на одном слайде.
- **Пример:**
```kotlin
limitFontVariety = 3
```

`contrastThresholds(...)`
- **Тип:** Параметры типа `Double`
- **Описание:** Минимальные уровни контрастности между текстом и фоном.
- **Пример:**
```kotlin
contrastThresholds(minContrastForText = 4.5, minContrastForLargeText = 3.0)
```

## Header Rules — правила заголовков слайда
Блок `header { ... }` задаёт требования к оформлению заголовков слайда: обязательность форматирования и ограничение по количеству слов.

- **Пример использования**
```kotlin
header {
requireHeaderFormat(maxWords = 10)
}
```
### Описание параметров

| Свойство             | Тип     | Обязательное | Описание                                   |
|----------------------|---------|--------------|--------------------------------------------|
| headerFormatRequired  | Boolean | Нет          | Обязательно ли форматирование заголовка.  |
| maxWordsCount        | Int     | Нет          | Максимальное количество слов в заголовке. |


### Подробности по параметрам
`requireHeaderFormat(maxWords: Int = 10)`
- **Тип:** `Int`
- **Описание:** Включает требование обязательного форматирования заголовка и задаёт максимальное количество слов.
- **Пример:**
```kotlin
requireHeaderFormat(maxWords = 10)
```

## Lists Rules — правила форматирования списков
Блок `lists { ... }` устанавливает требования к спискам на слайдах: размер, капитализация, знаки препинания, минимальное количество элементов.

- **Пример использования**
```kotlin
lists {
listSizeRange = 7
uniformCapitalizationRequired = true
singleItemsForbidden = true
endPunctuationForbidden = true
}
```

### Описание параметров

| Свойство                      | Тип      | Обязательное | Описание                                                  |
|-------------------------------|----------|--------------|-----------------------------------------------------------|
| listSizeRange                 | Int?     | Нет          | Разрешённый размер списка (число элементов).             |
| uniformCapitalizationRequired | Boolean  | Нет          | Требование единого стиля написания (заглавные/строчные).  |
| endPunctuationForbidden       | Boolean  | Нет          | Запрет на знаки препинания в конце пунктов списка.        |
| singleItemsForbidden          | Boolean  | Нет          | Запрет на списки из одного пункта.                         |


## Numbering Rules — правила нумерации слайдов
Блок numbering `{ ... }` задаёт необходимость нумерации слайдов.
- **Пример использования**
```kotlin
numbering {
slideNumberingRequired = true
}
```
### Описание параметров

| Свойство               | Тип     | Обязательное | Описание                      |
|------------------------|---------|--------------|-------------------------------|
| slideNumberingRequired  | Boolean | Нет          | Обязательна ли нумерация слайдов. |


## Graphics Rules — правила по соотношению текста и изображений
Блок `graphics { ... }` устанавливает ограничение по проценту текста на изображениях.
- **Пример использования**`
```kotlin
graphics {
maxTextPercentage = 70
}
```
### Описание параметров

| Свойство          | Тип   | Обязательное | Описание                                    |
|-------------------|-------|--------------|---------------------------------------------|
| maxTextPercentage | Int?  | Нет          | Максимально допустимый процент текста на изображениях. |

## Content Rules — ограничения по содержимому слайда
Блок `content { ... }` задаёт лимиты по количеству строк и слов на слайде.
- **Пример использования**
```kotlin
content {
limitTextPerSlide(maxLines = 10, maxWords = 40)
}
```
### Описание параметров

| Свойство           | Тип   | Обязательное | Описание                      |
|--------------------|-------|--------------|-------------------------------|
| maxLinesPerSlide    | Int?  | Нет          | Максимальное количество строк. |
| maxWordsPerSlide    | Int?  | Нет          | Максимальное количество слов.  |

### Подробности по параметру

`limitTextPerSlide(maxLines: Int? = null, maxWords: Int? = null)`

- **Тип:** два параметра типа `Int?`
- **Описание:** Задаёт ограничения на максимальное количество строк и слов на слайде. Если параметр не указан, ограничение не применяется.
- **Пример:**

```kotlin
limitTextPerSlide(maxLines = 10, maxWords = 40)
```
